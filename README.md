# Weather App 🌤️

A simple weather app built using HTML, CSS, and JavaScript.

## Features

- Search weather by city
- Shows current temperature
- Shows humidity
- Shows wind speed
- Changes weather icons based on weather conditions
- Shows an error for an invalid city

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API
